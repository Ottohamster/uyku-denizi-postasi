# Uyku Denizi Postası

Haftalık kişisel anestezi ve reanimasyon gazetesinin telefon uygulaması (PWA).

- `index.html` son sayıyı açar; `sayilar.json` sayı listesidir.
- `sayilar/` etkileşimli sayılar, `pdf/` yazdırılabilir kopyalar.
- Yeni sayı: `python3 araclar/sayi_ekle.py --sayi N --tarih YYYY-AA-GG --html ... --pdf ... --manset ... --konu ... --yb ... --agri ...`
